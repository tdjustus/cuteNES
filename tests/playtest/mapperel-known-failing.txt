# Holy Mapperel (tier 2): each ROM must identify the right board, find the
# expected memory sizes, and report DETAILED TEST RESULT 0000 (zero is normal;
# anything else is an unexpected mapper behavior). Expectations come from the
# ROM names and the Holy Mapperel README, never from this emulator's output.
# The ROM's font encodes letters as tile codes 1..26, hence `font a1`.
#
# Name key: M<mapper>_P<PRG ROM>_C<CHR ROM> | CR<CHR RAM>, S<battery RAM>,
# W<work RAM>, _V/_H fixed mirroring. No S/W means no PRG RAM.
#
# KNOWN FAILING (label known-failing; excluded from CI, run with
# `ctest -L known-failing`). Each entry states the correct hardware result;
# it fails because the emulator disagrees. Move an entry to mapperel.txt when
# it is fixed.
#  - MMC1 SUROM (512K PRG): detailed result 0300 instead of 0000.
#  - MMC3 (M4_*): the ROM never draws a result screen.
entry mapperel-m1-p512k-cr8k-s32k
rom ../../third_party/holy-mapperel/testroms/M1_P512K_CR8K_S32K.nes
font a1
run 1200 none
expect-text 001 S
expect-text 512K PRG ROM
expect-text 8K CHR RAM OK
expect-text DETAILED TEST RESULT: 0000
expect-text 32K PRG RAM OK
end
